Overview & Workbench

mono-harness provides a clean workbench for AI agents and human engineers. The lifecycle runs entirely from plain, committed markdown, repository scripts, and pre-commit hooks. The zharness binary acts as a scaffolding and synchronization utility — not a resident runtime. Delete the binary and every derived artifact, and the entire development lifecycle still executes, because the only irreplaceable bytes are the ones Git is already tracking.

Committed Markdown is Truth

Core

The binary is a scaffolding tool, not a runtime. Plans, decisions, memories, and playbooks live in plain markdown tracked by Git.

Three Verbs, Zero Daemons

Go CLI

zharness owns exactly install, update, and uninstall. Zero resident background daemons, zero SQLite database files.

Two Fail-Closed Guards

Guards

Pre-commit hooks re-execute validation proofs on approval and reject self-judging on high-risk lanes. CI verifies pushed commits.

Quickstart

Get up and running with the full bootstrap installer, install skills independently via skills.sh, or scaffold managed documentation with the zharness CLI.

bash — quickstart sh 
# 1. Clone and run the full bootstrap installer
$git clone git@github.com:therealtinhtute/mono-harness.git ~/mono-harness
$cd ~/mono-harness
$bash setup/install.sh

# 2. Or add skills to your current agent workspace
$npx skills add therealtinhtute/mono-harness

# 3. Scaffold and manage repo documentation with zharness
$zharness install

The 6-Stage Lifecycle Chain

Durable engineering initiatives move forward through a deterministic, auditable stage chain. Every stage references a markdown playbook and records progress directly into the active plan.

/brainstorm

Explore options, validate feasibility, lock requirements into active plan

→

/to-plan

Structure approach, phases, waves, tasks, and acceptance criteria

→

/work

Execute wave-by-wave, verify deliverables with concrete evidence

→

/check

Run pre-commit gates, re-execute proof commands, independent judge review

→

/git

Stage changes, enforce conventional commits, push, and open PR

→

/handoff

Persist session state and next actions in active plan

Alongside the primary chain, /watzup reconstructs context when resuming a cold session. For bounded tasks that do not require multi-wave bookkeeping, reduced modes like /work simple, /check bounded, and /brainstorm explore provide rapid execution without durable ledger overhead.
