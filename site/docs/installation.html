Installation

Three entry points — the full bootstrap, the skills on their own, or the CLI on its own. Pick the smallest one that matches what you want.

Prerequisites

  • Node.js 18+ for skill installation and the statusline.
  • jq for the statusline.
  • SSH access to git@github.com:therealtinhtute/mono-harness.git.
  • An authenticated gh CLI and tar, for the release installer.

After any install, review ~/.claude/settings.json and configure ANTHROPIC_AUTH_TOKEN as your environment requires.

Full Claude Code bootstrap

The installer installs the global CLAUDE.md, the rules, hooks, a settings template, and the statusline; backs up files before replacing them; and installs every repository skill globally through npx skills add.

Bootstrap

git clone git@github.com:therealtinhtute/mono-harness.git ~/mono-harness
cd ~/mono-harness
bash setup/install.sh

An existing ~/.claude/settings.json is preserved rather than overwritten.

Skills only

List the published skills without installing them, or install the whole set for Claude Code in one command.

Skills

# list the published skills
npx skills add git@github.com:therealtinhtute/mono-harness.git --list

# install all skills for Claude Code, globally
npx skills add git@github.com:therealtinhtute/mono-harness.git -a claude-code -g -y

Install zharness

The release installer installs the latest release of the workflow CLI to ~/.local/bin/zharness for Linux or macOS on amd64 or arm64.

CLI

bash scripts/install-zharness.sh
zharness --version

First run

Before durable planning or execution, initialize the project. zharness init creates the root harness.db, replays existing changesets, and scaffolds the managed workflow docs under docs/.

Init

cd /path/to/project
zharness init --json

From there the durable path is /brainstorm → /to-plan → /work → /check → /git → /handoff — see Workflow for the reduced modes when you only need a bounded change.
