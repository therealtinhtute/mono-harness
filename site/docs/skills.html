Skills Catalog

Fourteen skills organized into three distinct groups: Workflow, Craft, and Shipping. Each skill is packaged as a standard SKILL.md directory with optional references/ and scripts/ for progressive detail.

Overview

The skills adhere to the skills.sh specification and operate across Claude Code and other agent environments. Thin triggers front the skills, referencing canonical execution procedures in docs/playbooks/ to guarantee repeatable, transparent execution across all agent sessions.

Skill Groups Summary

Workflow · 8 brainstorm to-plan work check handoff watzup git interview — Core lifecycle from discovery and architecture to plan execution, verification, and commit.
Craft · 4 write librarian create-skill prompt-leverage — Precision prose, external GitHub exploration, skill authoring, and prompt engineering.
Shipping · 2 create-cli turbo-mono-platform — CLI interface architecture and full-stack TypeScript monorepo development.

Workflow Skills (8)

Workflow skills govern the full lifecycle of a development initiative: requirement locking, phased planning, wave execution, quality gates, and git operations.

brainstorm

workflow

Explore design options, evaluate architecture trade-offs, and lock requirements into docs/plans/active/{slug}.md.

Trigger: /brainstorm [idea, @files, or trade-offs]
Output: Locked spec in active plan

to-plan

workflow

Translate a locked specification into execution phases, dependency waves, explicit tasks, and verifier checks.

Trigger: /to-plan [plan-slug]
Output: Phased execution roadmap in active plan

work

workflow

Execute approved plan tasks wave-by-wave, run targeted verifications per task, and update progress in the plan ledger.

Trigger: /work [plan-slug or phase]
Output: Verified code changes & task updates

check

workflow

Pre-commit and pre-merge gatekeeper. Runs automated test suites, linters, security audits, and architectural validation.

Trigger: /check
Output: Gate verdict (APPROVED / REQUEST_CHANGES)

handoff

workflow

Persist session state, current progress, decisions made, and the exact next step into the active plan for seamless resumption.

Trigger: /handoff
Output: Current State block in active plan

watzup

workflow

Recap session position: inspects branch state, committed and uncommitted changes, and active handoffs to recommend next actions.

Trigger: /watzup
Output: State summary and prioritized next steps

git

workflow

Git operations with Conventional Commits. Handles surgical staging, secret scans, branch management, and pull request creation.

Trigger: /git [commit|push|pr]
Output: Atomic commits and clean pull requests

interview

workflow

Grill intent through structured questions. Systematically walks every branch of a decision tree before implementation begins.

Trigger: /interview [topic or problem]
Output: Disambiguated requirements and constraints

Craft Skills (4)

Craft skills focus on authoring quality, external repository investigation, skill engineering, and prompt refinement.

write

craft

Write and edit English and Vietnamese prose that sounds natural, concise, and audience-aware. Eliminates robotic AI filler.

Trigger: /write [draft or instructions]
Output: Polished documentation or UI copy

librarian

craft

Research external repositories via the GitHub CLI. Searches code, locates symbol definitions, and gathers citations without cloning.

Trigger: /librarian [owner/repo or search-term]
Output: Evidence-backed code citations

create-skill

craft

Create or upgrade agent skills adhering to the skills.sh standard. Generates structured SKILL.md, references, and validation tests.

Trigger: /create-skill [skill-name]
Output: Validated skill directory and metadata

prompt-leverage

craft

Strengthen raw, ambiguous prompts into execution-ready instruction sets with strict role boundaries, context, and criteria.

Trigger: /prompt-leverage [raw prompt]
Output: Structured, actionable prompt specification

Shipping Skills (2)

Shipping skills provide domain expertise for full-stack platforms and CLI tooling.

create-cli

shipping

Architect developer CLI tools: command hierarchies, flag naming, POSIX/GNU conventions, config loading, and packaging roadmaps.

Trigger: /create-cli [tool name or script]
Output: CLI specification and architecture roadmap

turbo-mono-platform

shipping

Full-stack TypeScript monorepo specialist: Turborepo, Next.js, Hono, tRPC, Drizzle ORM, Supabase, Tailwind CSS, and shadcn/ui.

Trigger: /turbo-mono-platform [layer or task]
Output: Scaffolded packages, schemas, and endpoints
