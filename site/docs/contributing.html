Contributing

Read CONTRIBUTING.md before opening a pull request. Report vulnerabilities privately through SECURITY.md. Never commit API keys, access tokens, private settings, or local harness state.

Iterate on a skill

Add the directory to Claude Code and edit the skill directly under skills/. Keep SKILL.md focused on routing and execution; move deep detail into references/ and reusable logic into scripts/.

Local iteration

claude-code add-dir /path/to/mono-harness

Validate a skill

Validation

bash scripts/validate-skill.sh skills/workflow/work/SKILL.md

Build and test the CLI

The CLI targets Go 1.25 and builds with CGO disabled. The GitHub Actions workflow runs the same build, vet, and test gates for changes under cli/.

Build, vet, test

cd cli
CGO_ENABLED=0 go build ./...
go vet ./...
go test ./...

Check documentation references

This checks repo-relative documentation claims against the files present in the checkout — backtick and markdown-link citations alike.

Doc links

bash scripts/verify-doc-links.sh

Before you open a PR

The repository is MIT-licensed and ships a Contributor Covenant code of conduct. Two pre-commit habits keep the history clean: run the narrowest validation for what changed (a skill, the CLI, or the docs), and never stage secrets or local harness state. The full checklist lives in CONTRIBUTING.md.
