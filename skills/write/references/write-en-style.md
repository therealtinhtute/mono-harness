# write-en-style

Use this file as the softer tone layer for English prose.

## Mode: clean
Use when the user wants neutral, natural, competent prose.

### Prefer
- short openings
- plain verbs
- calm confidence
- direct structure

### Avoid
- corporate polish for its own sake
- fake warmth
- decorative cleverness

---

## Mode: builder
Use for technical notes, product thinking, engineering write-ups, founder/builder voice.

### Prefer
- problem first
- practical tradeoffs
- concrete examples early
- mild personality without performance

### Useful rhythm
- claim
- why it matters
- example or implication

### Avoid
- lecture tone
- philosophical detours
- bloated transitions

---

## Mode: playful-lite
Use when the user wants a little more warmth or wit, but still needs clean prose.

### Prefer
- one light turn of phrase at a time
- self-aware phrasing over sarcasm at the reader
- short asides used sparingly

### Avoid
- meme voice
- stacked jokes
- emoji by default
- trying to make every line quotable

---

## Mode: docs
Use for English docs/help text.

### Prefer
- action first
- constraints early
- examples before long explanation
- consistent terminology

### Avoid
- storytelling intros
- marketing voice inside instructions
- vague expected outcomes
