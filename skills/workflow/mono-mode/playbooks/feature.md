# Playbook: feature

1. `brainstorm` — classify the lane and `lock` the Goal; a tiny request needs no plan and goes straight to `work bounded`.
2. `to-plan` — high-risk lane only; normal plans already carry phase `main`.
3. `work full` — red → green per requirement; each `done` names its acceptance check.
4. `check full` — an independent judge on the final phase; an inconclusive or wrong-surface result is not a pass.
5. `git` — commit, push or PR only when the owner asks.
6. `handoff` — record Current State; close the plan after a clean final check.

Reply: the outcome, the acceptance results, and the furthest delivery state reached.
