# Autoplan Lite Example

## Example — autoplan-lite

### Input

```text
Autoplan-lite this: I need a landing page for a side project this weekend. Just help me get a practical plan.
```

### Output

```text
Goal
Ship a practical landing page for a side project this weekend.

Context
The user wants a lightweight planning pass, not a deep product process.

Assumptions
- One-page site is enough for v1.
- Existing hosting probably already exists.

Open questions
- Main conversion action?
- Existing brand/assets?

Scope
- Messaging
- Page sections
- Build and publish steps

Non-goals
- Full brand system
- Complex CMS setup

Constraints
- Weekend timeline
- Lightweight execution

Spec
Create a simple landing page with clear value proposition, basic trust signals, and one main CTA.

Phases
1. Messaging lock
2. Page structure
3. Build and publish

Tasks
- Define audience, promise, and CTA.
- Draft section list and lightweight copy.
- Choose the fastest implementation path.
- Build page and test on mobile.
- Publish and verify CTA flow.

Risks
- Scope creep into a full marketing site.

Next recommended action
Lock CTA + section list first, then build with the fastest stack already available.
```
