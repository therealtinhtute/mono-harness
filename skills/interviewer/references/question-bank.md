# Question Bank

## Core / Product

| Question | Purpose |
|----------|---------|
| "If you could only ship ONE thing, what would it be?" | Force prioritization |
| "What's the cost of NOT solving this problem?" | Validate importance |
| "What would make you consider this a failure?" | Define success criteria |
| "Who's the most important user persona and why?" | Identify target user |
| "What's the MVP vs nice-to-have?" | Scope boundaries |

## Technical

| Question | Purpose |
|----------|---------|
| "What happens when [component] fails or is unavailable?" | Error handling |
| "How will this scale when [metric] grows 10x?" | Scalability |
| "What's the backup plan if [technology] doesn't work out?" | Risk mitigation |
| "How do you handle [edge case] in the data model?" | Data integrity |
| "What are the security implications of [decision]?" | Security review |

## UX / User Flows

| Question | Purpose |
|----------|---------|
| "What does a first-time user see before any data exists?" | Empty states |
| "How do you communicate [error type] to the user?" | Error messaging |
| "What's the recovery path when [action] fails?" | Error recovery |
| "How does this work on slow connections?" | Performance UX |
| "What's the onboarding flow?" | First-run experience |

## Edge Cases

| Question | Purpose |
|----------|---------|
| "What if [unusual input]?" | Input validation |
| "What if user does [unexpected action]?" | Defensive design |
| "What if [external dependency] is down?" | Graceful degradation |
| "What if data is [corrupt/missing/duplicate]?" | Data integrity |
| "What if user has [accessibility need]?" | Accessibility |

## Trade-offs

| Question | Purpose |
|----------|---------|
| "Why this approach vs [alternative]?" | Decision rationale |
| "What are you trading off for [benefit]?" | Hidden costs |
| "What will be harder to change later?" | Lock-in risks |
| "What assumptions are we making?" | Surface assumptions |
