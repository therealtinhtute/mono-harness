# Playbook: research

Writes only notes and drafts in the scratchpad or a directory the owner names; no code change, plan or commit.

1. `read` — search with the first connected provider (TinyFish → Exa → Firecrawl → native); pick the sources worth reading.
2. `read` — fetch each source through its cascade (local → gh/raw → MCP → opt-in proxy); never send a private URL to a third party.
3. `learn` — digest and outline in the mode the request implies; contradictions stay visible.
4. `write` — polish the draft; skip for Quick Reference notes.
5. The findings call for a code change → re-route to `feature` or `bug-fix`.

Reply: the answer or artifact path first, then Sources (URL, fetch tier), then open questions.
