# Playbook: investigation

Read-only: write no file, plan or commit.

1. `think` for a decision or judgment; `hunt` for a concrete symptom.
2. Read the code, docs and Git history the answer depends on; run read-only commands.
3. Cite a file and line, a command output or a commit for every claim.
4. The answer calls for a code change → stop and re-route to `bug-fix` or `feature`; a wrong premise → say so.

Reply: the answer first, its evidence, and what would change it.
