## Wave 1
### T1 — Drift-guard test
- type: test
- inputs:
  - embedded playbooks, scaffolded `.kit/docs/playbooks/`
- touches:
  - `cli/internal/embedded/embedded_test.go` (or a new test file)
- avoid:
  - playbook content edits
- steps:
  1. Write a test that, for each playbook, reads the embed and asserts an `init`-scaffolded copy is byte-identical.
  2. Run it against the current tree (must pass now that Phases 1 & 3 re-scaffolded `.kit/docs/`).
- expected outputs:
  - a failing test if anyone hand-edits `.kit/docs/` out of sync with the embed
- verification:
  - `cd cli && go test ./internal/embedded/ -run Projection` → pass; then hand-edit a scaffold copy, re-run → FAIL (capture both)
- stop if:
  - the scaffold and embed can't be compared deterministically (line endings, trailing newline)
- escalate to:
  - to-plan phase single-source-playbooks

- expected outputs:

- verification:
